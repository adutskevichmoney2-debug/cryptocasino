# CryptoCasino — Frontend

Полноценный фронтенд криптовалютного казино и букмекера уровня крупных проектов (Stake / 1win): тёмный премиальный дизайн, мультиязычность, рабочие модалки, кошелёк с монетами и сетями, спорт с купоном ставок и аккуратные точки интеграции под всё, что требует лицензий и бэкенда.

> **Статус:** этап 1 — только frontend. Этап 2 — Vercel (деплой) + Supabase (auth, БД, storage) + платёжный модуль и игровые провайдеры. Все точки подключения описаны в [INTEGRATION.md](./INTEGRATION.md).

## Стек

- **Next.js 16** (App Router) + **TypeScript**
- **Tailwind CSS 4** — дизайн-токены в `src/app/globals.css`
- **Zustand** (+persist) — auth / кошелёк / купон / настройки
- **Framer Motion** — анимации модалок, дропдаунов, шторок
- **react-hook-form** — формы и валидация
- **lucide-react** — иконки

## Запуск

```bash
npm install --legacy-peer-deps
npm run dev        # http://localhost:3000
npm run build      # продакшн-сборка
npm run lint
```

## Что уже работает (без бэкенда)

- **Регистрация / вход / восстановление пароля** — модалки с валидацией полей, ошибки в маленьких тостах (занятый email, неверный пароль и т.д.). Сессия сохраняется. Мок-«база» на localStorage, пароли — только SHA-256 хэши.
- **Честный баланс** — все 12 монет по нулям, пока не подключены бэкенд и реальные депозиты. Никаких фейковых сумм.
- **Кошелёк** — выбор монеты (BTC, ETH, USDT, USDC, BNB, SOL, TRX, TON, LTC, DOGE, XRP, ADA) и сети (USDT: TRC-20 / ERC-20 / BEP-20 / TON / Solana / Polygon и т.д.), вывод с проверкой формата адреса по сети, минималок и баланса; история транзакций с пустыми состояниями.
- **Казино** — лобби с поиском, фильтром по провайдерам, сортировкой и категориями; 48 игр с оригинальными обложками; страница игры с режимами «реальная/демо» и зоной под iframe провайдера; избранное.
- **Спорт** — live и предстоящие события по 8 видам спорта, рабочий купон (ординар/экспресс, расчёт выигрыша, ошибки «войдите» / «недостаточно средств»).
- **Профиль** — обзор, загрузка/смена/удаление фото (сохраняется), смена пароля, приватность, формат коэффициентов, KYC-заглушка, транзакции, история ставок.
- **10 языков** — RU (по умолчанию), EN, UK, ES, PT, DE, TR, ZH, HI, FR. Язык хранится в cookie → корректный SSR без «мигания».
- **Бонусы, VIP-клуб (5 уровней), турниры с таймерами, реферальная программа.**
- **Поддержка** — FAQ по категориям, форма обращения, виджет чата.
- **Мелочи** — куки-баннер, модалка 18+, страница 404, уведомления, тосты, адаптив от 320px, нижняя навигация и шторки на мобильных.

## Замечания по контенту

- **Изображения хранятся в `assets-b64/`** (base64) и автоматически декодируются в `public/` при `npm install` / `npm run dev` / `npm run build` (`scripts/decode-assets.mjs`). Причина: код заливался в GitHub через API, принимающий только текст. На Vercel всё работает из коробки. При подключении провайдера с его CDN-ассетами `assets-b64/` и скрипт удаляются.
- Названия игр вымышленные, обложки — оригинальный арт: ничего не нарушает права провайдеров. При подключении реального провайдера каталог заменяется его ассетами (см. `lib/data/games.ts`).
- Юридические тексты (`lib/data/legal.ts`) — шаблоны RU/EN с плейсхолдерами `[COMPANY]`, `[JURISDICTION]`, `[LICENSE NO.]`; перед продакшном их должен вычитать юрист.
- Фото для спорт-баннеров — бесплатный сток (Unsplash), лицензия допускает коммерческое использование; при желании замените на брендовые.
